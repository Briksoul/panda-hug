**跨文化适应知识库**

第一部分 核心理论模型

## 1.1 Berry文化适应理论（双维度模型）

【理论核心】Berry提出文化适应是一个双维度的过程，基于两个核心问题：

是否保留自己的文化身份和特征？（保持传统文化）

是否寻求与主流文化群体建立积极关系？（融入宿主文化）

【四种文化适应策略】

|  |  |  |  |
|:--:|:--:|:--:|:--:|
| **策略类型** | **保持传统文化** | **融入宿主文化** | **特征描述** |
| 整合（Integration） | 是 | 是 | 既保持原有文化身份，又积极参与宿主社会，被认为是适应性最好的策略 |
| 同化（Assimilation） | 否 | 是 | 放弃原有文化，完全融入主流文化 |
| 分离（Separation） | 是 | 否 | 保持原有文化，避免与主流文化接触 |
| 边缘化（Marginalization） | 否 | 否 | 既失去原有文化根基，又无法融入主流文化，适应性最差 |

【实证研究结论】采用整合策略的个体体验到的压力最少，心理和社会文化适应最佳；采用边缘化策略的个体压力最大，适应结果最差；同化和分离策略的适应结果处于中间水平

【在中国留学生中的验证】Lai等人(2023)对315名在美中国留学生的研究发现：分离是中国学生最偏好的策略，边缘化最不受欢迎；中国学生在社会文化适应方面表现最好，但在学术适应方面表现最差；偏好分离和边缘化策略的学生心理和学术适应更好，而整合和同化策略与更好的社会文化适应相关

## 1.2 U型曲线假说（U-Curve Hypothesis）

【理论提出者】Lysgaard (1955)，后由Gullahorn & Gullahorn (1963)发展

【理论核心】文化适应过程呈现U型曲线，经历四个阶段：蜜月期/兴奋期（Honeymoon Phase）：初到新环境，对新文化充满好奇和兴奋，一切都显得新鲜有趣；危机期/文化休克期（Culture Shock Phase）：新鲜感消退，开始面临语言、社交、生活方式等各种困难，产生挫败感和焦虑；恢复期/调整期（Recovery Phase）：逐渐适应新文化，掌握应对技能，情绪开始好转；适应期/mastery期（Adjustment Phase）：能够熟练应对新环境，达到稳定的适应状态

## 1.3 W型曲线模型（W-Curve Model）

【理论核心】W型曲线是U型曲线的延伸，包含出国适应和回国再适应两个U型过程：第一U型（出国适应）：蜜月期 → 文化休克 → 恢复期 → 适应期

第二U型（回国再适应/反向文化休克）：回国兴奋期 → 反向文化休克 → 再适应恢复期 → 再适应稳定期

【反向文化休克（Reverse Culture Shock）】

定义：回到母国后，由于已经适应了外国文化，对母国文化反而感到陌生和不适应

特点：往往比初始文化休克更严重，因为人们通常预期回国会很容易，缺乏心理准备

来源【台湾留美学生回国适应研究】

影响因素包括：性别、回国意愿、海外经历满意度、母国人们的对待方式

其他影响因素：父母期望、职业考虑、对母国的热爱、生活方式偏好

## 1.4 压力-适应-成长动态模型

【理论核心】跨文化适应本质上是一个双重过程：既是充满挑战和压力的过程，也是学习和成长的过程。

【辩证循环过程】压力（Stress）：进入新文化环境，面对陌生的社会规范、价值观和行为方式，产生认知失调和心理压力；适应（Adaptation）：个体通过学习和调整，发展出新的应对策略和行为模式；成长（Growth）：每一次压力-适应循环后，个体的功能适应性和心理健康水平都得到提升

【核心观点】适应不是一次性完成的，而是通过多次"压力-适应-成长"的辩证循环逐步实现的；最终结果是个体逐渐发展出跨文化身份（intercultural identity），超越单一文化的局限；沟通是驱动适应过程的核心引擎，包括东道文化规范下的沟通能力、人际沟通和大众传播参与

【在中国学生中的验证】

Li (2022)对中国留学生的研究发现，中国学生的跨文化适应过程基本符合压力-适应-成长动态模型和U型曲线模型。

影响因素包括：年龄、性别、语言水平、在东道国停留时间、动机

最显著的外部因素是母国的技术发展

## 1.5 文化休克理论（Culture Shock Theory）

【定义】文化休克是人们突然被移植到国外时患上的一种职业病。像大多数疾病一样，它有自己的症状、原因和治疗方法。

【症状表现】

心理层面：孤独感、焦虑、抑郁、易怒、无助感

生理层面：疲劳、失眠、食欲变化、头痛

行为层面：回避社交、过度依赖同胞群体、对东道文化产生敌意

## 1.6 文化智力理论（Cultural Intelligence, CQ）

【四维结构】

|  |  |  |
|:--:|:--:|:--:|
| **维度** | **定义** | **适应预测作用** |
| 元认知文化智力（Metacognitive CQ） | 对自身文化假设的思考和调控能力 | 预测文化判断与决策、任务绩效 |
| 认知文化智力（Cognitive CQ） | 对不同文化规范、价值观、习俗的知识 | 预测文化判断与决策 |
| 动机文化智力（Motivational CQ） | 体验多元文化的兴趣、信心和驱动力 | 预测文化适应（一般、互动、工作） |
| 行为文化智力（Behavioral CQ） | 根据文化情境调整言语和非言语行为的能力 | 预测文化适应、任务绩效 |

【实证研究结论】CQ能够在人口统计学特征、一般认知能力、情绪智力、经验开放性之外，额外解释文化适应和绩效的变异

【在中国的国际学生研究】

文化智力与跨文化适应、心理韧性呈显著正相关

心理韧性在文化智力影响跨文化适应的过程中起中介作用

## 1.7 社会认同理论视角

【理论基础】Tajfel & Turner (1979) 的社会认同理论

【核心观点】

1\. 歧视与文化适应策略的关系：感知到的歧视 → 感知到群体边界不可渗透 → 回避主流社会 + 强化自身文化背景

2\. 社会认同策略：社会流动（Social Mobility）：试图离开原有群体，加入地位更高的群体;社会创造（Social Creativity）：重新定义比较维度，在原有群体中寻找积极面;国际学生通过这两种策略维持积极的社会认同，最终发展出双文化身份

3\. 共同内群体认同模型（Common Ingroup Identity Model）：美国东道主对采用整合和同化策略的中国学生更愿意沟通，评价更积极

## 1.8 思乡与孤独（Homesickness & Loneliness）

【思乡的多维结构】想念家人（Missing family）;想念朋友（Missing friends）;适应困难（Adjustment difficulties）;孤独感（Loneliness）

【关键发现】思乡是普遍现象：荷兰约50%，英国约80%的学生体验到思乡;英国学生思乡程度更高，女性比男性更思乡;思乡与抑郁相关，被概念化为一种微型哀伤

【国际学生的孤独感】

国际学生比美国本土学生更容易感到孤独、思乡，感觉把一部分自己留在了家里

社会网络对国际学生的适应很重要，但亲密朋友的数量并不预测对社会网络的满意度

**第三部分 中国留学生赴美文化适应特征**

## **3.1 文化适应策略偏好**

【主要发现】分离（Separation）是中国学生最偏好的文化适应策略；边缘化是最不受欢迎的策略；中国学生在社会文化适应方面表现最好，但在学术适应方面表现最差

【策略与适应的关系】偏好分离和边缘化策略的学生 → 心理和学术适应更好；偏好整合和同化策略的学生 → 社会文化适应更好；学术适应的显著预测因素是心理适应，而非社会文化适应

## **3.2 文化适应压力源分析**

【核心发现】中国学生在美国的生活并不容易，必须承受多方面的生活压力：

语言障碍与沟通困难；教学模式转变（从被动接受转向主动参与）；生活方式变化

；社交孤立与文化隔阂；经济压力与工作限制；家庭期望与学业压力

【休闲与文化适应压力】休闲参与是应对文化适应压力的有效工具；但在某些情况下，休闲也可能导致负面结果；由于独特的文化影响和国际学生身份，中国学生体验到独特的文化适应压力源

## **3.3 心理健康状况与风险因素**

【主要发现】文化适应压力和适应不良完美主义对抑郁有显著主效应；存在显著的三向交互作用：文化适应压力、适应不良完美主义、在美时间长度共同预测抑郁；低适应不良完美主义仅对在美时间较长的学生有缓冲作用；对于在美时间较短的学生，即使完美主义水平低，文化适应压力仍会导致较高抑郁

【澳大利亚中国学生心理健康研究】三大主题：心理压力、感知安全、社会孤立；心理压力来源：语言障碍、教学模式转变、生活方式变化；感知安全：缺乏安全感、种族歧视感知；社会孤立：归属感降低、缺乏亲密人际关系、孤独和思乡感；提出三方互动风险因素模型解释国际学生情绪适应

## **3.4 社会支持与社会联结**

【社会联结与主观幸福感】

【主要发现】主流社会联结（Mainstream SC）部分中介文化适应与生活满意度、积极情绪的关系；族群社会联结（Ethnic SC）部分中介文化融入与消极情绪的关系；意外发现：主流社会联结也部分中介文化融入与生活满意度、积极情绪的关系；结论：主流社会联结和族群社会联结对中国国际学生都是重要的应对资源

【社会因素与主观幸福感轨迹】

【主要发现】

消极情绪和生活满意度各识别出4种不同的轨迹类别；轨迹类型包括：持续高幸福感、经历文化休克、幸福感提升、低幸福感；与主流社会的社会联结对生活满意度轨迹的预测力优于与族群社区的社会联结；倾诉困扰的舒适度和自评英语水平仅对生活满意度轨迹有显著预测作用

## **3.5 双文化身份与幸福感**

【核心研究】

【研究方法】

【双文化身份整合的两个构念】文化和谐（Cultural harmony）：两种文化身份之间的协调程度；文化融合（Cultural blendedness）：两种文化身份的融合程度

【主要发现】文化和谐是实现幸福感的关键预测因素；文化适应压力在文化和谐与实现幸福感之间起中介作用；沉浸时间长度调节了文化和谐通过文化适应压力影响实现幸福感的间接效应；促进文化和谐可以增强双文化个体的实现幸福感并减少文化适应压力；但文化适应压力的影响可能因文化沉浸时间和暴露程度而异

## **3.6 学术适应与学业表现**

【学术适应特点】中国学生在学术适应方面表现最差（相对于社会文化和心理适应）；学术适应的显著预测因素是心理适应，而非社会文化适应；这意味着心理健康状况对学业成功至关重要

【教学模式差异带来的挑战】从中国的被动接受式学习转向美国的主动参与式学习；课堂讨论、口头报告、批判性思维要求带来巨大压力；学术写作规范差异（引用格式、论证方式等）

【期望与现实的落差】40%的学生经历严重的失败恐惧和家庭期望压力；只有17%的学生经历一系列严重的学习相关问题（沟通和学业压力）

**第四部分 美国学生来华文化适应特征**

## **4.1 语言学习与跨文化适应**

【跨文化能力的四个维度】情绪韧性（Emotional resilience）；灵活性/开放性（Flexibility/openness）；感知敏锐度（Perceptual acuity）；个人自主性（Personal autonomy）

【主要发现】跨文化能力与语言接触共同解释了语言熟练度提升的37.7%；语言接触对熟练度有直接影响；跨文化能力通过语言接触产生间接影响（中介效应）

【文化休克意识的重要性】研究对象：CIEE（国际教育交流委员会）项目的美国交换学生；文化适应四阶段：预期 → 文化休克 → 迷失方向 → 适应；重要发现：虽然大多数人认为亚裔美国人由于亚洲血统会经历较少文化休克，但研究显示他们缺乏"文化休克意识"反而处于劣势；文化休克意识不足会延迟适应，阻碍中文学习成功；建议：通过课堂文化适应减少社会距离、促进社会互动

## **4.2 身份认同与自我呈现**

【研究方法】质性研究，29名美国大学生；在中国一学期的中文留学项目；每月一次非正式个人访谈

【主要发现】部分数据证实了先前研究：一些学生的美国人身份认同在留学期间得到加强

；但学生们对自己的中文水平感到非常自豪；他们完全接受自己的"外国人身份"，并利用这一身份为自己谋利；在中国学习似乎没有对这组学生的身份协商和自我呈现构成严重威胁

【研究意义】支持了对更广泛语言背景和留学情境学习者进行研究的呼吁；有助于更全面地理解留学的复杂性

## **4.3 文化适应策略与应对方式**

【研究方法】关键事件技术 + 建构主义扎根理论方法；13名有在中国留学经历的本科生深度访谈

【主要发现】美国大学生如何感知中国的新学习环境；学生采用哪些策略来适应新文化【实践建议】项目结构与学生个人学习需求和抱负之间的兼容性；使用服务型社区建设活动促进美国学生与东道主之间的互动参；在美国学生反思文化沉浸体验时纳入本土视角

## **4.4 社交媒体与跨文化适应**

【主要发现】在线沟通增强了学生的留学体验；在社会文化技能、信息需求、关系纽带、心理健康方面提供帮助；与朋友和与家人/亲密对象沟通时偏好不同平台与同胞的在线沟通既缓冲了留学生的文化适应压力，也缓解了远方家人的压力和担忧
